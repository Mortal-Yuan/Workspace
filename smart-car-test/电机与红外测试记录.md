# 智能小车电机与红外测试记录

记录日期：2026-08-25

工程：`smart-car-test`

主程序：`main/main.c`

主控：ESP32-S3

开发框架：ESP-IDF 5.4.4

## 1. 三轮位置与驱动通道

小车使用三个全向轮，三个轮子位于等边三角形的三个角。

| 驱动通道 | 实际位置 | 驱动板输出 |
| --- | --- | --- |
| A | 右轮 | M1/A 路 |
| B | 后轮 | M2/B 路 |
| C | 左轮 | M3/C 路 |

以上位置均已通过单轮运行测试确认。

## 3. 电机控制规则

程序速度范围为 `-1000` 至 `1000`，当前默认速度为 `400`，即约 40% PWM 占空比。

单路电机控制规则：

| 速度值 | IN1 | IN2 | PWM |
| --- | --- | --- | --- |
| 大于 0 | 1 | 0 | 速度绝对值 |
| 小于 0 | 0 | 1 | 速度绝对值 |
| 等于 0 | 0 | 0 | 0 |

### 3.1 已确认的直行组合

| 动作 | A 右轮 | B 后轮 | C 左轮 |
| --- | ---: | ---: | ---: |
| 前进 `w` | `-speed` | `0` | `-speed` |
| 后退 `s` | `speed` | `0` | `speed` |
| 停止 `x` | `0` | `0` | `0` |

实际测试已确认：`A=-400、B=0、C=-400` 时小车向前移动。

### 3.2 串口测试命令

| 命令 | 功能 |
| --- | --- |
| `1` | 仅运行 A 路右轮 |
| `2` | 仅运行 B 路后轮 |
| `3` | 仅运行 C 路左轮 |
| `w` | 前进 |
| `s` | 后退 |
| `x` | 三轮停止 |
| `+` | 速度增加 50，最高 800 |
| `-` | 速度减少 50，最低 100 |
| `r` | A、B、C 三路依次短测 |

`a`、`d` 的三轮全向运动组合尚未实车标定，暂不作为有效的左转、右转命令使用。

## 4. 四路红外模块

模块型号：`LQ-IR4CHV6`

供电：3.3 V

接口：`VCC、GND、OUT1、OUT2、OUT3、OUT4`

### 4.1 接线及实际左右顺序

| 物理位置 | 模块信号 | ESP32-S3 | 当前日志位序 |
| --- | --- | --- | --- |
| 最左 | OUT4 | GPIO5 | `L` |
| 左中 | OUT3 | GPIO4 | `LC` |
| 右中 | OUT2 | GPIO2 | `RC` |
| 最右 | OUT1 | GPIO1 | `R` |

物理位置从左到右为：

```text
最左 OUT4(GPIO5) | 左中 OUT3(GPIO4) | 右中 OUT2(GPIO2) | 最右 OUT1(GPIO1)
```

当前程序按物理顺序输出 `IR[L,LC,RC,R]`，并将低电平有效信号归一化为 `1=黑色、0=白色`。下方测试值是早期调试时记录的 GPIO 原始电平，保留用于核对模块电气行为。

### 4.2 识别电平

| 探头状态 | GPIO 原始值 | 模块指示灯 |
| --- | --- | --- |
| 检测到黑色 | 0 | 亮 |
| 检测到白色 | 1 | 灭 |

红外识别为低电平有效。

### 4.3 已确认的测试值

以下字符串顺序均为 `OUT1 OUT2 OUT3 OUT4`：

| 黑色所在位置 | 原始值 |
| --- | --- |
| 仅最右 | `0111` |
| 最右和右中 | `0011` |
| 仅最左 | `1110` |
| 最左和左中 | `1100` |

每种状态均连续读取 10 次且结果一致。

## 5. 当前结论

1. A、B、C 三路电机和三组编码器均能工作。
2. A 为右轮、B 为后轮、C 为左轮。
3. 前进组合已经实车确认，后退使用其反向组合。
4. 四路红外的物理顺序、GPIO 映射和低电平有效逻辑均已确认。
5. 三轮横移和原地旋转组合仍需后续实车标定。

完整接线、超声波接口、巡线算法升级和当前锐角失败实验见 [项目开发与实验日志.md](项目开发与实验日志.md)。
