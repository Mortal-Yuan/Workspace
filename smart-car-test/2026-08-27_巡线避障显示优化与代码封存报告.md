## 2. 最终运行合同

### 2.1 顶层安全合同

- 上电进入 `IDLE`，最终电机命令为 `0,0,0`。
- 短按 BOOT 或串口 `f` 启动自动巡线/避障；RESET 是显示启用后仍然可用的物理
  停车方式。
- `app_controller` 是唯一运动仲裁器，电机驱动是最终硬件写入点。
- 控制周期为 20 ms；显示刷新在独立低优先级任务中执行，不阻塞控制任务。

### 2.2 当前巡线基线

巡线几何来自 2026-08-25 最终版本 `10c8414`，保留模块化接口并加入经过现场验证的
选择性动力修正：

| 项目 | 当前值 |
| --- | --- |
| 红外顺序 | `L/LC/RC/R`，黑线为 1 |
| 加权值 | `-6/-2/+2/+6` |
| 误差 | `weighted / active_count` |
| 修正 | `clamp(error × 100, -250, 250)` |
| 直线 | 基础速度 360 |
| 普通弯 | 基础速度 250，轮命令上限 400 |
| 单侧边缘 | 基础速度 190，轮命令上限 320 |
| 全白 `0000` | 按锁存方向以 320 搜线，未锁向时默认向左 |
| 方向确认 | 相反方向连续 3 个周期才切换 |
| 方向保持 | 未确认反向时误差幅度至少为 4 |

最终 A/C 公式仍为：

```text
A = -base + correction
B = 0
C = -base - correction
```

没有恢复“所有非零轮统一抬高”的全局死区补偿。当前只保留两类局部修正：

1. 绝对目标达到 200 的驱动轮，在刚进入驱动角色或换向时输出至少 500，持续
   150 ms；低需求内侧轮不参加该增力。
2. 单探头图案 `0001/0010` 的 A 内侧轮和 `0100/1000` 的 C 内侧轮最低正向命令
   为 100，解决 `0010: 8,0,-320`、`0100: -320,0,8` 无法带车转弯的问题。

### 2.3 当前超声与避障基线

| 项目 | 当前值 |
| --- | --- |
| Trig / Echo | GPIO6 / GPIO13 |
| 测量截止 | 45 ms |
| 触发周期 | 70 ms |
| 障碍触发 | 原始 Echo 在 20～100 mm，包含 100 mm |
| 启动授权 | 连续 3 次可信远距回波 |
| 回线确认 | 连续 5 个控制周期见黑线 |
| 制动/停稳 | 每段 150 ms |
| 左移 | 500 启动、380 稳态，1231 ms |
| 前进 | 500 启动、400 稳态，1191 ms，名义约 19 cm |
| 右移 | 500 启动、380 稳态，最多 960 ms |

正常 `CLEAR` 巡线期间，只有 20～100 mm 的真实原始 Echo 可以中断巡线。空旷地的
无回波、`NO_RETURN`、干净的远距离 `OUTLIER`、低 Echo 超时和其他超声异常仅保留
诊断，不再造成转弯或红外图案切换时误停车。启动阶段仍要求三次可信远距回波，避免
传感器完全失效时直接授权起步。

当前避障状态序列为：

```text
SENSOR_CHECK -> CLEAR
CLEAR -> BRAKE -> LEFT_15CM -> SETTLE_FORWARD
      -> FORWARD_19CM -> SETTLE_RIGHT -> RIGHT_12CM
      -> LINE_CONFIRM -> CLEAR
```

- 右移期间首次见到任意黑线，在同一 20 ms 控制周期立即输出零并进入
  `LINE_CONFIRM`，不继续依靠惯性跑满 960 ms。
- 960 ms 内没有找到黑线、确认期间丢线、避障运动中再次出现近障或连续不确定事件
  达到上限，进入锁存 `FAILSAFE` 并停车。
- 完成过一次避障后，巡线再遇到 `1111` 进入锁存 `FINISHED`；避障完成前的
  `1111` 仍按普通巡线图案处理。
- 障碍阈值从 60 mm 提高到 100 mm 后，车辆理论上早停约 40 mm；前进段因此由
  940 ms 增加到 1191 ms，以补回这段纵向距离。

### 2.4 横移运动学补偿

三轮 Kiwi 逆运动学继续统一处理横移。当前参数为：

- 侧轮几何系数：866‰。
- 左移反偏航补偿：50%。
- 右移反偏航补偿：50%，独立参数保留，便于以后继续单侧标定。
- 纯横移 A/C 最低有效命令：300。
- B 轮正向最低有效命令：460。

该补偿用于抵消左移逆时针、右移顺时针的现场偏航。左右距离仍为开环时间标定，
不是编码器闭环距离。

## 3. 今日问题、原因与修正

| 现象 | 定位原因 | 最终修正 |
| --- | --- | --- |
| 低速轮被强制抬高后弯径增大、稳定性下降 | 全局非零最低命令覆盖巡线数学结果 | 移除全局死区抬升，仅保留驱动轮短时增力和单探头 100 命令 |
| 直线偶尔不起步、弯道卡住 | 外侧驱动轮切换或换向时 PWM 不足 | 绝对目标≥200的驱动轮使用500/150 ms选择性增力 |
| `0010/0100` 转弯动力不足 | 内侧轮只有约8/1000 | 对应内侧轮提高到100，不触发500增力 |
| 转弯/红外切换时偶发长时间停车 | 超声朝向变化产生 `OUTLIER`、无回波或远距脉冲，旧策略误入停车状态 | `CLEAR` 中仅20～100 mm真实原始回波能够停车 |
| 空旷地完整长 Echo 被混同为故障 | 量程外完整下降沿缺少独立分类 | 增加 `NO_RETURN`，并将截止时间调整为45 ms |
| 障碍物过近才触发 | 60 mm制动余量不足 | 阈值提高到100 mm，显示告警同步调整 |
| 提高阈值后避障前进不足 | 车辆比原先早停约40 mm | 前进段940→1191 ms，名义15→19 cm |
| 左右横移伴随反向旋转 | 三轮安装、负载和电机差异造成偏航 | 左右独立50%反偏航补偿，保留A/C和B轮有效输出下限 |
| 右移找到黑线后仍冲过 | 旧逻辑只在固定时段末检查 | 首次见线同周期制动，再静止确认5周期 |
| 避障后无法区分赛道终点 | `1111` 与普通巡线图案共用语义 | 避障完成后启用锁存 `FINISHED` 终点状态 |
| TFT 接线后无显示 | 初版错误假设 ST7789 240×240，实际为 LQ_TFT18SPIV33/ILI9163B | 替换为龙邱 ILI9163B 序列和162×132布局，RST改接GPIO47 |
| 显示 SDI 接入后 USB 消失 | ESP32-S3 原生 USB D+ 与 GPIO20 共用 | 烧录时临时拔SDI；运行时先关闭USB诊断再由显示接管GPIO20 |

## 4. 状态屏最终实现

显示模块为 `LQ_TFT18SPIV33`，使用 ILI9163B 兼容控制器和 162×132 横屏区域。
最终接线为：

| 显示引脚 | ESP32-S3 |
| --- | --- |
| D/C | GPIO38 |
| SDI/MOSI | GPIO20 |
| SCK | GPIO45 |
| CS | GPIO3 |
| RST | GPIO47 |
| VCC/GND | 3V3/共地 |

屏幕显示模式、四路红外、超声距离、避障状态、三轮命令和
`READY/RUNNING/FINISHED/FAILSAFE`。IDLE 时 GPIO47 保持低电平，使屏幕黑屏并避免
残留旧的 `RUNNING` 画面。显示任务只接收覆盖式快照；SPI 刷新不进入 20 ms 控制
关键路径。

GPIO20 同时是原生 USB D+。今后每次烧录应先断开 `SDI--GPIO20`，烧录并正常复位
后再接回。显示接管 GPIO20 后串口 `x` 不可用，应使用 RESET 停车。屏幕最终颜色、
方向和可视边界仍需在实物接回 SDI 后确认。

```powershell

```

源文件 SHA-256 和依赖范围记录在
`main/control/archive/2026-08-27_巡线与避障封存清单.md`。今后修改活动巡线或避障
前，应先创建新的版本标签和清单，避免覆盖这次实车可用基线。
