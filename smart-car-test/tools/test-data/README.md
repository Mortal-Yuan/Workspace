# 实物角度样本

两张样本均为2026-09-10实际摄像头无标记预览，160×120，逐行RGB332，每文件19200字节。

- `cube-angle-original.rgb332`：先前角度，预期中心约(78,75)。
- `cube-angle-side.rgb332`：用户重新旋转后确认仍在中央的绿色正方体，预期中心约(77,38)。
- `cube-angle-side-dark.rgb332`：同角度较暗的实时帧，预期中心约(76,38)，用于建立归一化轮廓和绿色分布模板。
- `cube-far-dark.rgb332`：正面远处实拍，预期中心约(79,21)，用于验证0x29暗绿量化像素与浅色背景抑制。
- `cube-grab-position.rgb332` / `.ppm`：用户确认合适抓取位置，中心约(73.8,68.0)、面积1557像素，对应frame15698。

样本来自各自时间点的整帧实拍，包含背景，用于检查角度变化和背景误检。颜色编码与小车预览一致；测试无需Pillow。物块身份由用户提供，二维形状算法只输出候选。
