# USB 摄像头枚举实验

这是一个独立于小车运行固件的安全探测程序，用于验证 ESP32-S3 的
GPIO19（USB D-）、GPIO20（USB D+）能否枚举 USB 摄像头。

- 启动时强制拉低电机使能、三个 PWM 和六个方向引脚；
- 不初始化红外、超声波、显示屏和运动控制任务；
- 日志固定从 UART0/CP210x 输出；
- 只读取 USB 设备、配置、接口描述符，不启动视频流。

日志出现 `CAMERA_RESULT=PASS_UVC` 表示接线和 UVC 接口枚举通过。该结果
只证明控制传输正常；后续还要依据描述符协商 MJPEG 分辨率并验证连续帧。

2026-08-28 实机枚举结果：`VID=349c`、`PID=3307`、产品名 `HD video`，
识别到两个 UVC 接口以及麦克风、扬声器 UAC 接口，结果为
`CAMERA_RESULT=PASS_UVC`。
