# 摄像头 Wi-Fi 实时预览

该实验固件把已经验证的 USB UVC MJPEG 图像通过 ESP32-S3 SoftAP 和 HTTP
传回浏览器。它不会启动小车控制，电机使能、三个 PWM 和六个方向引脚均
保持低电平。

## 使用方法

1. 电脑连接 Wi-Fi：`SmartCar-Camera`；
2. 密码：`smartcar123`；
3. 浏览器打开：`http://192.168.4.1/`；
4. 页面会显示实时画面、分辨率、累计帧数和丢帧数。

摄像头现已按正向重新安装，网页直接按 MJPEG 原始方向显示，不再旋转 180°。
MJPEG 原始帧不做解码和重编码；后续黑线识别也应使用原始坐标方向，确保
左右转向含义与预览画面一致。

默认协商 MJPEG 640x480 @ 15fps；不支持时自动尝试 320x240 @ 30fps。
只允许一个 MJPEG 页面同时取流，防止多个浏览器耗尽 UVC 帧缓冲区。
