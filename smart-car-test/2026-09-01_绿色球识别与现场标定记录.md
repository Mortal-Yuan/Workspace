# 2026-09-01 绿色球识别与现场标定记录

## 1. 目标与安全边界

本轮只加入识别能力，不加入寻找、靠近或推球动作。球检测结果只进入摄像头快照和串口遥测，
不参与巡线、避障或最终电机仲裁。全部现场采样期间模式保持 `IDLE`，`cmd=0,0,0`。

## 2. 实现

- 复用UVC摄像头已有的MJPEG 640×480@15 FPS输入和80×60 RGB888解码图。
- 新增 `main/control/camera_ball_vision.c/.h`，使用颜色门限、八邻域连通域、面积、填充率、
  圆形比例和边缘距离筛选绿色球。
- 快照新增颜色、候选/确认、球心、尺寸、面积、形状、置信度、平均RGB和绿色探针字段。
- 连续3帧同色且球心变化不超过200‰才确认；切换到远处候选会重新计数。
- 主机测试覆盖灰背景、绿圆、偏置绿圆、边缘绿圆、红圆、蓝圆、微小绿噪点和细长绿区域。

## 3. 现场标定过程

初始门限 `G>=45`、`G-max(R,B)>=15`、`G/RGB>=380‰` 时，连通域数量始终为0。加入不参与判定的
最绿像素探针后，现场绿球区域测得约 `RGB=75/101/98` 至 `59/82/80`，属于低饱和青绿色，
因此门限调整为：

| 参数 | 当前值 |
| --- | ---: |
| G最低值 | 35 |
| G相对R/B优势 | 2 |
| G占RGB总量 | 345‰ |
| 最小整帧面积 | 5‰（80×60时约24像素） |
| 最小包围盒填充率 | 350‰ |
| 最小短边/长边 | 600‰ |
| 图像边缘留白 | 2像素 |
| 球心连续容差 | 200‰ |
| 确认帧数 | 3 |

放宽颜色后，内部候选反复稳定在 `x=+389..+425`、`y=176..194`，尺寸约62～75‰×100～133‰，
平均RGB约 `37..41 / 39..44 / 26..32`，多次达到连续3帧确认。左边缘另有约 `x=-850` 的低饱和
绿色连通域；加入2像素边缘约束后，它仍显示在诊断字段中，但 `candidate=0`，不再计为球。

## 4. 遥测解释

```text
BALL=color/candidate/detected/stable_frames
bxy=center_x/center_y
bwh=width/height
ba=area
bshape=fill/roundness
bconf=confidence
brgb=mean_r/mean_g/mean_b
bpix=matched_pixels
bc=green_component_count
bprobe=green_score/x/y/r/g/b
```

绿色编号为1。`candidate=1` 表示当前帧通过颜色和形状，`detected=1` 表示球心连续性也已累计到
3帧。所有坐标和比例均为千分比。
