# 2026-09-04 绿色球替代黄色球标定记录

## 结论

黄色球与红球在当前摄像头、灯光和压缩条件下容易混淆，本轮改用绿色球作为第二个待推送球。
绿球识别已完成现场标定和移除对照测试，可以进入后续任务状态机开发；当前识别结果只用于
摄像头快照、串口遥测和调试窗口，不会触发电机，也没有改变已经调好的巡线与避障逻辑。

## 当前识别参数

现场绿球呈低饱和、偏青的深绿色，球区域平均值约为：

```text
R=79..83, G=98..102, B=97..106
```

采用的主要门限如下：

| 项目 | 当前值 |
| --- | ---: |
| 普通像素最低G | 55 |
| 普通像素G-R最低差值 | 18 |
| 普通像素B-G最大差值 | 20 |
| 强像素最低G | 75 |
| 强像素G-R最低差值 | 18 |
| 强像素B-G最大差值 | 10 |
| 远处候选最少像素 | 4 |
| 远处候选最少强像素 | 2 |
| 远处候选最低置信度 | 650‰ |
| 远处候选最低圆形度 | 400‰ |
| 连续确认帧数 | 3 |

绿球使用独立检测通道，不会被通用红球/蓝色目标选择逻辑吞并。串口遥测中的 `GREEN` 字段
依次给出颜色、单帧候选、连续确认、稳定帧数，并附带远近、球心、面积、置信度、平均RGB、
匹配像素和包围盒数据。

## 有球测试

绿球可见时进行了15秒被动采样：

- `GREEN=1/1/1` 持续成立，稳定帧数从128增长到189；
- 远处球标志 `gfar=1`；
- 匹配像素随画面变化为4或8，置信度约872‰到900‰；
- `mode=IDLE`、`fresh=1`、`cam_err=0`、`cmd=0,0,0`、编码器0/0/0。

## 2026-09-04 双球任务接入

四目标同时摆放后，15秒静态采样得到：红球31/31帧确认、绿球29/31帧确认、右侧蓝区31/31帧

也不会被误选；若左蓝区暂不可见，先对准并靠近红球，左蓝区确认后立即停车进入路线对齐。

新增 `n` 双球任务入口：

1. 红球控制器从向左搜索开始，将红球送入锁定的左侧蓝区；
2. 三帧静止重叠确认完成后，电机保持零输出500 ms；
3. 控制器切换为独立绿球观测，从向右脉冲搜索开始，并在锁定前只接受右侧蓝区；
4. 找到绿球后沿用现有停车观察、短脉冲对齐、减速接近、入夹复核和推送闭环；
5. 绿球进入右蓝区并完成三帧确认后锁存 `MISSION_DONE`，电机保持零输出。

阶段转换不使用未经场地标定的固定角度盲转：绿球已经可见时立即停车对齐，否则才继续向右
搜索。原有 `b` 保留为独立红球测试，巡线和避障参数完全不变，`x` 可从任意任务阶段抢占停车。
