# 2026-08-26 模块化重构与横移避障开发总结

## 1. 今日最终成果

今天完成了固件模块化重构、巡线与硬件按键可靠性改造、三轮全向横移设计与
实验、矩形绕板避障状态机，以及多轮场地死区修正。旧的单文件主控
`main/main.c` 已由模块化实现完整替换；此前的实验日志、方案和审查记录继续
保留，没有用本总结覆盖历史结论。

当前固件已经烧录到 ESP32-S3。上电后保持 `IDLE`，三路电机命令为零；短按
BOOT 启动巡线与自动避障，RESET/EN 硬复位停车，串口 `x` 软件停车。

## 2. 固件重构

### 2.1 重构目标和审查过程

旧实现把硬件访问、巡线、避障、按键、命令、日志和故障处理集中在一个不断
增长的源文件中，修改任一功能都容易影响其他路径。重构前由独立计划 agent
提出方案，再由独立审查 agent 检查；计划经过两轮修订，补齐行为合同、双核
诊断隔离、超声事务竞态和多故障源表达后，第三轮审查通过，主 agent 才实施。
完整审查过程保存在《固件模块化重构计划.md》。

### 2.2 当前模块边界

| 目录 | 职责 |
| --- | --- |
| `main/app` | 顶层模式、命令意图、唯一运动仲裁、配置 |
| `main/control` | 纯控制策略：巡线、避障监督器、kiwi 逆运动学 |
| `main/drivers` | 电机、编码器、红外、HC-SR04、BOOT 驱动 |
| `main/platform` | 引脚定义和 ESP-IDF 电机硬件适配 |
| `main/diagnostics` | 静态队列、低优先级格式化、UART/USB 分片输出 |
| `main/core` | 跨模块配置、传感器、运动、诊断类型 |
| `test/host` | 直接编译生产 C 模块的主机回归测试 |

顶层控制器是唯一可以选择最终电机命令的模块，`motor_driver_apply()` 是唯一
最终电机写入点。控制周期不动态分配内存；相同命令不重复写硬件；换向先把该
轮 PWM 清零；全零命令关闭 EN/STBY，非零命令在方向和 PWM 写好后才使能。

故障按电机、平台中断、红外、超声、按键和配置分别保存，不再由互相矛盾的
多个布尔标志覆盖。诊断格式化和串口发送移出高优先级控制周期，避免日志阻塞
运动控制。HC-SR04 使用非阻塞边沿捕获、session/token 和临界区结算，保证完整
Echo 脉冲不会与同一周期的超时处理竞争。

### 2.3 巡线和按键重构

巡线保留四路红外的物理顺序 `L/LC/RC/R`，使用 `-6/-2/+2/+6` 权重、方向锁存
和三周期反向确认。BOOT 改为明确的“只启动”事件：按下稳定 50 ms、释放稳定
80 ms 才重新装填，上电保护 500 ms；保护期内的有效短按排队，上电时已经按住
则必须先释放。顶层模式统一为 `IDLE/AUTONOMOUS/MANUAL/SELF_TEST/FAULT`，解决
多次按键后无法再次启动和运行标志混乱的问题。

现场发现低速容易陷入死区后，最终巡线参数提高为：

| 场景 | 最终值 |
| --- | ---: |
| 直线 | 420/1000 |
| 普通转弯 | 310/1000，命令上限 500 |
| 单侧边缘 | 280/1000，命令上限 450 |
| 全白搜索 | 360/1000 |
| 非零转弯轮最低命令 | 220/1000 |
| 启动或换向增力 | 500/1000，持续 150 ms |

由于编码器会受到电机干扰，本版没有把噪声计数用于堵转闭环，而是使用较高的
稳态下限和启动/换向增力降低静摩擦死区风险。

## 3. 新避障算法

### 3.1 设计思路

黑线被木板截断后，车辆不再采用“固定转角后沿恒定距离绕行”的方案。该方案
既依赖木板边缘稳定测距，又无法保证回线角度，可能沿黑线反方向行驶。新方案
利用三轮全向底盘保持车头大致不变，以矩形平移绕过木板：先左移越过近侧板边，
再向前越过木板，最后向右横移重新找到原黑线。这样不需要用多次开环转向恢复
航向，回线后车头理论上仍朝原行驶方向。

状态机为：

```text
SENSOR_CHECK
  -> CLEAR（巡线）
  -> BRAKE
  -> STRAFE_LEFT_EDGE
  -> STRAFE_LEFT_CLEARANCE
  -> SETTLE_FORWARD
  -> FORWARD_BYPASS
  -> SETTLE_RIGHT
  -> STRAFE_RIGHT_LINE
  -> LINE_CONFIRM
  -> CLEAR（恢复巡线）
```

### 3.2 触发、找边和回线

- 启动后先停车，连续取得 3 次可靠的前方清空观测才允许巡线。
- 巡线时首次出现 20～200 mm 的真实原始 Echo 就立即停车，不等待中值或跳变
  滤波接受该突变。
- 停稳 150 ms 后向左横移。至少横移 200 ms，并连续 3 次确认可靠远距或
  Echo-low 无回波，才认为超声探头越过木板边缘。
- 找到板边后继续左移 800 ms。该值是第一轮场地参数，尚不能等同于精确 10 cm。
- 再停车 150 ms，向前运行 2500 ms。该值同样是临时约 40 cm 参数。
- 再停车 150 ms，慢速向右横移寻找黑线。
- 任一红外首次检测到黑线时，同一控制周期立即输出零，避免惯性冲过黑线；
  随后原地连续确认 5 个控制周期。确认失败则继续慢速右移，确认成功才恢复巡线。

### 3.3 安全保护

- 左移找板边和右移找线最长均为 5 s，超时进入 `FAILSAFE` 并保持停车。
- 运动期间连续 3 次超声不确定会故障停车，不把 Echo 卡高或无效脉冲误判为板边。
- 前进越板阶段再次检测到 200 mm 内障碍会立即进入 `FAILSAFE`。
- 各运动方向切换之间插入 150 ms 停稳段，减少矢量突变和惯性。
- RESET/EN 和串口 `x` 始终可停止；全零命令同时关闭电机驱动 EN/STBY。

## 4. 三轮横向移动设计与实测数据

### 4.1 已确认的底盘映射

- A：右轮；B：后轮；C：左轮。
- 前进：`A=-S, B=0, C=-S`。
- 已确认顺时针旋转：`A=+S, B=-S, C=-S`。
- 三轮位于约 120° 的 kiwi 全向布局。

根据已确认的前进、旋转方向和 120° 几何关系，理论横移基向量为：

| 运动 | A | B | C |
| --- | ---: | ---: | ---: |
| 左移 | `-0.866S` | `-S` | `+0.866S` |
| 右移 | `+0.866S` | `+S` | `-0.866S` |

该映射被集中在 `control/kiwi_kinematics`，避障状态机只输出车体前进、左移和
旋转分量，不直接散写 A/B/C 数值，便于未来加入 IMU 航向修正或速度闭环。

### 4.2 横移实验过程

1. 首轮使用 S=340、300 ms 的 `q/e` 限时实验。左右物理方向正确，三个轮子
   都参与，但左移时向左偏航、右移时向右偏航，且右侧更严重。
2. 加入 10% 反向偏航补偿后，旋转略有减小但仍明显；把测试时间延长到 1 s
   后确认该现象稳定存在，不是短时惯性。
3. 独立测试 B 轮发现明显方向性死区：`B=-340` 运行 1 s 时 B 计数约 181，
   `B=+340` 只有约 5，现场也确认正向基本不转；提高到 `B=+420` 后约 160，
   才与负向响应接近。
4. 补偿提高到 20% 后，纯计算会把 A/C 降到约 226，现场又落入 A/C 死区。
   因此运动学模块增加纯横移 A/C 最低输出，并对 B 正向单独设置最低输出。
5. 场地完整避障仍容易受静摩擦卡住，最终再次提高稳态和启动功率。

需要特别注意：B 轮负向单轮测试时，完全未驱动的 A/C 编码器也分别出现约
101/103 tick，证明电机干扰会造成跨通道假计数。上述编码器数据只用于说明
“存在明显异常或死区”的辅助证据，不能作为精确速度和距离标定。

### 4.3 当前横移和前进输出

横移基准为 S=380，反向偏航补偿为 20%，纯横移 A/C 最低 300，B 正向最低
460。当前实际稳态命令约为：

| 动作 | A | B | C |
| --- | ---: | ---: | ---: |
| 左移稳态 | -300 | -456 | +300 |
| 右移稳态 | +300 | +460 | -300 |
| 左移启动 150 ms | -333 | -600 | +333 |
| 右移启动 150 ms | +333 | +600 | -333 |

绕板前进稳态为 `A=-400, B=0, C=-400`，每个前进段开始先以
`A=-500, B=0, C=-500` 增力 150 ms。

## 5. 主要问题和解决方案

| 问题 | 原因或证据 | 当前解决方案 |
| --- | --- | --- |
| 木板边缘超声回波不稳定 | 斜边、近场盲区、Echo 丢失 | 最短横移时间、连续3次清空、质量检查和5s超时 |
| 回线后可能反向行驶 | 多次开环转向无法保证航向代数和 | 改为保持车头方向的左移—前进—右移矩形路径 |
| 右移偏航更严重 | B正向340处于死区 | B正向最低提高到460，20%反向偏航补偿 |
| 补偿后A/C停转 | 20%补偿把A/C计算值降到226 | 纯横移A/C最低提高到300 |
| 场地摩擦导致多阶段停住 | 稳态PWM和启动脉冲偏低 | 全面提高巡线/横移/前进输出，启动和换向使用500、150ms增力 |
| 编码器数据不可信 | 未驱动轮也产生大量tick，C曾出现不可能高频毛刺 | 暂不做编码器速度/距离闭环，以直尺和时间中位数标定 |
| 超声固件曾显示Echo高和8m脉冲 | 探头贴桌面导致声学通道被遮挡 | 恢复正常朝向后验证231～263mm连续有效；保留Echo-high保护 |
| 首次见线容易因惯性冲过 | 横移中直接等待稳定图案会太晚 | 任一红外首次见黑立即停车，再原地确认5周期 |
| BOOT多次按压后状态混乱 | 多运行标志和固定冷却窗口 | 单一顶层模式、50ms防抖、80ms释放重装、500ms启动保护 |
| 日志可能拖慢控制 | 控制任务内格式化/发送 | 静态队列交给低优先级诊断任务，控制任务只发布结构化快照 |

## 7. 下一轮场地测试重点

1. 测量“板边后左移 800 ms”的实际距离，至少重复 5 次，取中位数修正为 10 cm。
2. 测量前进 2500 ms 的实际距离，至少重复 5 次，取中位数修正为 40 cm。
3. 记录是否进入 `LEFT_EDGE/LEFT_CLEARANCE/FORWARD_BYPASS/RIGHT_LINE/LINE_CONFIRM`
   以及失败时的最终状态，区分传感器异常、运动死区和搜索超时。
4. 检查提高功率后是否出现明显冲线；若有，优先缩短右移制动距离/降低右移稳态，
   不降低各轮到已确认死区以下。
5. 若开环矩形路径仍有明显累计偏航，下一步接入 MPU6500 航向闭环；若要采用
   编码器距离闭环，必须先解决线束、电源和软件毛刺过滤问题。
