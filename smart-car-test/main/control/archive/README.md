# 巡线实验归档

当前活动的 `main/control/line_follow.c` 保留 2026-08-25 最终差速巡线结构，并于
2026-08-27 针对动力不足增加选择性驱动轮增力。当前参数为：直线 360、普通弯
250/上限 400、单侧边缘 190/上限 320、搜索 320、`Kp=100`、最大修正 250、
方向确认 3 周期、方向保持误差 4。绝对目标达到 200 的驱动轮在进入驱动角色或
换向时使用 500/150 ms；`0010/0100` 的内侧轮单独设为 100，仍低于增力阈值，
其他内侧低需求轮不增力，也不存在全轮非零最低命令。

`line_follow_speed_only_2026-08-27.c.disabled` 保存随后进行的“只做弯道降速”
隔离实验：居中与全黑时 A/C 同速，其他非零图案只降低 A/C 同速值，`0000`
停车；它不计算加权误差、差速、方向锁存或丢线搜索。

`.disabled` 扩展名使归档文件不参与 ESP-IDF/CMake 编译。若以后重新启用该实验，
应先封存当前活动实现，再将归档文件移回 `main/control/line_follow.c`，并同步配置、
主机测试和现行文档；不要让两套实现同时参与编译。

2026-08-27 当前活动巡线与避障基线已通过带注释 Git 标签
`archive-2026-08-27-line-obstacle-v1` 封存。完整范围、源码哈希、参数和恢复方法见
[`2026-08-27_巡线与避障封存清单.md`](2026-08-27_巡线与避障封存清单.md)。该标签
固定完整依赖闭包；不要只复制 `line_follow.c` 或 `obstacle_supervisor.c` 覆盖新版本。
